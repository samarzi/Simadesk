# Fix WB Orders + Redesign AllOrdersModule

## Problem
1. **WB orders don't load** — `AllOrdersModule._loadFromApi` silently skips WB when `isWbCoolingDown()` returns true (line 387). No error shown, user sees empty WB section.
2. **AllOrders page is hard to use** — no clear store names per order, no status category tabs, hard to navigate with many orders.

## Files to Modify

### 1. Fix WB Loading — `src/modules/AllOrdersModule.ts`

**A) Show cooldown warning (line ~387)**
- When `isWbCoolingDown()` → set a visible warning instead of silently returning
- Add a `private wbWarning = ''` field, set it when cooldown detected
- Render a yellow banner at top of WB orders section: "WB rate-limit — подождите N сек"
- Clear the warning when cooldown expires and data loads

**B) Surface API errors (lines 414-416)**
- Catch block should set `this.lastError` or a per-MP error state
- Show error in the table area for WB

### 2. Fix WB Data Mapping — `src/services/wbApi.ts`

**A) Price fallback bug (line 884)**
```typescript
// BEFORE (broken — 0 || totalPrice skips zero-price orders):
const price = Number(r.priceWithDisc ?? r.totalPrice ?? r.finishedPrice ?? 0) || 0;
// AFTER:
const price = Number(r.priceWithDisc ?? r.totalPrice ?? r.finishedPrice ?? 0);
```
