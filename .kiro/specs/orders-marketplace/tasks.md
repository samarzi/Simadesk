# Implementation Plan: orders-marketplace

## Overview

Реализация разделов «Маркетплейсы» и «Заказы» в SPA STOCKBASE (TypeScript + Vite).

**Структура навигации:**
- **Маркетплейсы** (группа)
  - **Ozon** - управление товарами (синхронизация, цены, остатки - существующий функционал)
- **Заказы** (отдельный пункт) - все заказы из всех маркетплейсов в едином интерфейсе с фильтрацией по источнику (Ozon, Wildberries и др.) и схеме доставки (FBO/FBS/RealFBS)

Включает: расширение типов, новый API-сервис для заказов, новый модуль для управления заказами, обновление навигации в `index.html` и `App.ts`, а также покрытие property-based тестами (fast-check) и unit-тестами (Vitest).

## Notes

- Задачи, помеченные `*`, являются опциональными и могут быть пропущены для ускорения MVP
- Каждая задача ссылается на конкретные требования для трассируемости
- Property-тесты используют библиотеку **fast-check** (минимум 100 итераций)
- Unit-тесты и property-тесты дополняют друг друга
- Все запросы к Ozon API идут через прокси `/ozon-api` с заголовками `Client-Id` / `Api-Key`
- `AbortController` используется для отмены загрузки при нажатии «Стоп» или повторном `refresh()`
- **Архитектура разделов:**
  - **Маркетплейсы → Ozon**: управление товарами (синхронизация, цены, остатки) - существующий функционал
  - **Заказы**: единый интерфейс для всех заказов из всех маркетплейсов с фильтрацией по источнику и схеме доставки (FBO/FBS/RealFBS)
- **API ключи:** берутся из соответствующих разделов маркетплейсов (например, из раздела Ozon)
- **Масштабируемость:** структура `OrdersModule` поддерживает добавление новых маркетплейсов (Wildberries, Яндекс.Маркет и др.) без изменения архитектуры
