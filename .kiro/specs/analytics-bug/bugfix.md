# Bugfix Requirements Document

## Introduction

Аналитика неправильно рассчитывает чистую прибыль для Yandex.Market, показывая завышенные значения. Пользователь получил от Yandex.Market выплату 460K (грязная прибыль), но модуль аналитики показывает чистую прибыль 1.2M за год. Даже без учета себестоимости прибыль должна быть примерно 460K, что указывает на использование неправильной метрики выручки (цена для клиента вместо выплаты продавцу).

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN AnalyticsModule рассчитывает чистую прибыль для Yandex.Market транзакций с использованием метода `calcYmRevenue` THEN система использует `priceForCustomer` (цена для клиента) вместо фактической выплаты продавцу

1.2 WHEN метод `calcYmRevenue` обрабатывает Yandex.Market транзакции THEN система рассчитывает выручку как сумму `priceForCustomer * count`, что дает завышенную выручку по сравнению с реальной выплатой

1.3 WHEN Yandex.Market транзакция имеет поле `amount` (фактическая выплата) THEN система не использует это поле в качестве базовой выручки, что приводит к несоответствию между реальной выплатой и рассчитанной чистой прибылью

### Expected Behavior (Correct)

2.1 WHEN AnalyticsModule рассчитывает чистую прибыль для Yandex.Market THEN система SHALL использовать фактическую выплату продавцу (`amount` или корректно рассчитанное значение `accruals_for_sale`) вместо цены для клиента

2.2 WHEN метод `calcYmRevenue` обрабатывает Yandex.Market транзакции THEN система SHALL рассчитывать выручку на основе фактической выплаты продавцу, учитывая все вычеты (комиссии, доставка, другие сборы)

2.3 WHEN доступны оба поля `amount` и корректное значение `accruals_for_sale` THEN система SHALL отдавать приоритет полю, которое отражает реальную выплату продавцу после всех вычетов

### Unchanged Behavior (Regression Prevention)

3.1 WHEN AnalyticsModule рассчитывает чистую прибыль для WB и Ozon THEN система SHALL CONTINUE TO использовать существующие корректные методы расчета выручки без изменений

3.2 WHEN AnalyticsModule рассчитывает комиссии и другие расходы для всех маркетплейсов THEN система SHALL CONTINUE TO корректно классифицировать и суммировать расходы

3.3 WHEN AnalyticsModule отображает KPI и другие аналитические метрики THEN система SHALL CONTINUE TO корректно рассчитывать и отображать все показатели, кроме исправления выручки Yandex.Market
